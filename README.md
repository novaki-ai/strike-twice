# Novaki: Strike Twice

A 1930s rubber-hose cartoon action roguelite starring Novaki, the burnt-out matchstick who has to strike again.

```bash
npm install
npm run build   # static site in dist/, works from any sub-path
npm run dev     # local dev server
```

See [SUBMISSION.md](SUBMISSION.md) for the full feature list, controls, the `window.NOVAKI_QA` test interface,
how the assets were made, how it was tested, and known issues.
